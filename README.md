# 📊 Boditech Weekly Report Merger (주간회의자료 자동 병합 자동화)

본 프로젝트는 Microsoft Outlook에 수신된 각 팀의 주간회의자료(PPT)를 자동으로 검색, 다운로드하고 **하나의 PPT 파일로 자동 병합(Merge)** 해주는 파이썬 자동화 스크립트입니다. 
추가로 주간 보고서 미제출 팀(담당자)을 자동으로 필터링하여 알려주는 기능이 포함되어 있습니다.

---

## 🎯 주요 목적 및 기능
1. **아웃룩 메일 자동 검색**: 지정된 폴더(`[받은 편지함] -> [2. 영업관리] -> [(나)방민정]`)에서 오늘 날짜(YYMMDD)가 포함된 PPT 첨부 메일만 필터링합니다.
2. **조건 기반 다운로드**: 제목/본문/파일명 중 `회의자료` 또는 `주간회의자료` 키워드가 포함된 메일만 타겟팅합니다.
3. **PPT 자동 병합**: 추출된 여러 개의 PPT 파일을 양식(디자인)의 깨짐 없이 `주간보고병합.pptx` 파일 하나로 자동 통합합니다.
4. **미제출자 트래킹**: 사전에 등록된 8개 팀의 담당자 목록과 대조하여 주간 보고서 미제출 팀을 콘솔에 출력합니다.

---
